# Physics PRO100 Bot 🤖

Telegram bot for physics exam preparation.

## Features
- 📚 Theoretical material by topics
- 📝 Physics formulas with explanations
- 🔢 Problem solving with step-by-step solutions
- 🎯 Exam preparation system

## Setup for Bothost

1. Add this repository to Bothost: https://github.com/polinakrasko2025-lab/physics-pro100-bot
2. Set main file: `webhook_handler.py`
3. Set entry point: `handle_webhook`
4. Add environment variable: `TELEGRAM_TOKEN`

## Local Development
```bash
pip install -r requirements.txt
python main.py
